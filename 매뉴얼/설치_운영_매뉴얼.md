# 혼디 설치·운영 매뉴얼 (센터 담당자용)

## 1. 설치 환경

| 항목 | 요구 | 센터 PC 기준 |
|---|---|---|
| 운영체제 | Windows 10/11 64비트 | Windows 11 |
| CPU·메모리 | 4코어·8GB 이상 권장 | i7-8700 · 32GB |
| GPU | 불필요 | (GTX 1060 3GB 사용 안 함) |
| 디스크 | 설치 약 400MB + 세션 작업 공간(불러온 CSV 크기만큼) | |
| 파이썬 | 3.11~3.13(권장 3.12). 없으면 설치.bat이 winget으로 설치 시도 | |
| 브라우저 | Microsoft Edge(기본 설치) 또는 Chrome | PDF 변환에 사용 |
| 인터넷 | 설치 1회(pypi.org), 말로 묻기 시 api.openai.com | 데이터 분석 자체는 인터넷 불필요 |

설치되는 패키지(전부): duckdb 2.0.0, matplotlib 3.11.2, numpy, pillow, contourpy, cycler, fonttools, kiwisolver, packaging, pyparsing, python-dateutil, tzdata(의존 패키지). 모두 `.venv` 폴더 안에만 설치되어 PC의 다른 프로그램에 영향을 주지 않습니다.

## 2. 설치 순서

1. 제출 ZIP을 원하는 폴더에 풉니다(한글·공백이 있는 경로도 됩니다). 예) `C:\혼디\`
   실행 프로그램은 ZIP 안의 **`05_실행_소스코드\hondi\`** 폴더입니다. 이 폴더만 원하는 곳에 옮겨도 됩니다.
2. `05_실행_소스코드\hondi\설치.bat` 더블클릭. 화면에 [1/4]~[4/4]가 차례로 나옵니다.
   - [1/4] 파이썬 찾기: `py -3.12 → -3.13 → -3.11` 순으로 찾고, 없으면 `winget install Python.Python.3.12`(사용자 범위) 시도. 그래도 없으면 python.org 안내 후 멈춥니다.
   - [2/4] `.venv` 가상환경 생성
   - [3/4] 패키지 설치(`wheels\` 폴더가 있으면 인터넷 없이 그 폴더에서 설치)
   - [4/4] 설치 점검(아래 3장)
3. `config.ini`를 메모장으로 열어 필요한 값을 넣습니다(4장).
4. `실행.bat` 더블클릭 → 브라우저에 `http://127.0.0.1:8765` 가 열리면 완료.

예행 결과(2026-11-15, 개발 PC, 한글·공백이 든 새 폴더에 ZIP 풀기): 설치.bat 25초(패키지를 처음 내려받는 PC는 더 걸릴 수 있음), 자가 점검 [정상] 9 · [확인] 1(허브 키 없음). 이어서 예시 데이터 → 데이터 둘러보기 → 질문 카드 → 반출 고치기 → 실제 AI 말로 묻기 → 보고서 PDF·신청서·묶음 ZIP → 퇴실까지 14단계 통과. 8765 포트가 이미 쓰이면 8766으로 자동 전환되는 것도 확인했습니다.

> 파이썬이 PC에 이미 있는데 찾지 못하면 환경변수 `HONDI_PYTHON`에 python.exe 전체 경로를 넣고 설치.bat을 실행하세요.

### 의존성 목록

- 개발·검증용(선택): `requirements-dev.txt` (pytest, openpyxl, markdown)

## 3. 설치 점검(자가 진단)

설치.bat 마지막과 혼디 화면의 **설정·점검**에서 같은 결과를 봅니다.

| 항목 | [문제]일 때 |
|---|---|
| 파이썬 버전 | 3.11~3.13이 아니면 [확인]. 3.12 설치 권장 |

| AI 설정·허브 키 | 없으면 [확인]만 표시. 키 없이도 사용 가능 |

## 4. 설정(config.ini)과 환경변수

혼디는 **환경변수 없이** `config.ini` 한 파일로 설정합니다. 예시 파일은 `config.example.ini`이며, 설치.bat이 없을 때 복사해 `config.ini`를 만듭니다. 제출 ZIP의 `config.ini`에는 평가용 OpenAI 키가 들어 있습니다(대회 규정). 허브 프로젝트 키는 넣지 않았습니다.

```ini
[ai]
provider = openai
model = gpt-5-nano
key =                      ← OpenAI API 키
reasoning_effort = low
monthly_limit_krw = 20000

[hub]
project_key =              ← 제주데이터허브 프로젝트 키(선택)

[privacy]
send_aggregates = false
auto_delete = true
keep_results = false

[server]
port = 8765
```

| 선택 환경변수 | 쓰임 |
|---|---|
| `HONDI_PYTHON` | 설치.bat이 파이썬을 찾지 못할 때 python.exe 전체 경로 지정 |


| 구역·항목 | 기본값 | 설명 |
|---|---|---|
| `[ai] provider` | openai | `none`이면 AI를 아예 쓰지 않음(질문 카드만) |
| `[ai] model` | gpt-5-nano | 가장 저렴한 모델. 계획 품질이 부족하면 gpt-5-mini |
| `[ai] key` | (비움) | OpenAI API 키. 화면·기록에 표시되지 않음 |
| `[ai] reasoning_effort` | low | minimal / low / medium |
| `[ai] monthly_limit_krw` | 20000 | 이번 달 추정 사용액이 넘으면 AI 호출을 멈추고 카드로 진행 |
| `[hub] project_key` | (비움) | 제주데이터허브 Open API 프로젝트 키(방문 전 공개 데이터 미리보기) |
| `[privacy] send_aggregates` | false | 초록 결과의 집계값을 AI 해설에 보낼지. 센터 심의 전까지 false 권장 |
| `[privacy] auto_delete` | true | 퇴실·종료 시 세션 자료 삭제 |
| `[privacy] keep_results` | false | 삭제 시 결과물(out 폴더)만 남김 |
| `[server] port` | 8765 | 사용 중이면 8766~8775 자동 사용 |

### OpenAI 키 발급·관리
1. platform.openai.com → API keys → Create new secret key → `config.ini`의 `key =` 뒤에 붙여 넣기.
2. **Billing → Limits에서 월 사용 한도를 꼭 설정**하세요(혼디의 월 한도와 이중 안전장치).
3. 키가 유출되었거나 평가가 끝나면 키를 삭제(Revoke)하고 새로 발급하세요.

### 운영 비용 추정
| 항목 | 값 |
|---|---|
| 질문 1회(계획 수립) | 입력 약 3,900토큰 + 출력 약 450토큰 |
| 단가(gpt-5-nano) | 입력 100만 토큰당 0.05달러, 출력 0.40달러 |
| 질문 1회 비용 | 약 0.0004달러 ≈ **0.5원** (1달러=1,400원) |
| 예) 하루 100회 × 22일로 가정하면 | 약 1,200원/월 |
| 같은 질문 반복 | 계획 캐시로 0원 |
| 질문 카드 | 0원(AI 미사용) |

## 5. 데이터 흐름과 보안

```
[센터 조회 화면] --CSV 다운로드--> [사용자 PC 다운로드 폴더]
        --끌어다 놓기--> [혼디 세션 폴더(%LOCALAPPDATA%\Hondi\sessions\<세션>)]
        --DuckDB 메모리 집계(이 PC 안)--> [그림·표·보고서] --반출 신청--> [센터 심사]

[질문 문장] --값 방화벽(지역·업종·숫자 → 〔자리표시자〕)--> api.openai.com --계획 JSON--> 혼디
```

- 혼디 서버는 `127.0.0.1`(이 PC)에서만 열립니다. 다른 PC에서 접속할 수 없습니다.
- 외부 AI에는 **가려진 질문 + 공개 명세(컬럼명·업종 코드)**만 갑니다. 센터 데이터 값(행·집계)은 기본 설정에서 절대 나가지 않습니다. 보낸 글은 세션 폴더 `ai_log.jsonl`과 화면의 **AI 전송 기록**에 남습니다.
- 이용 기록(`activity.jsonl`)에는 데이터 종류·도구·신호등만 남고 지역명 같은 값은 남지 않습니다(코드로 강제).
- 퇴실 버튼·창 닫기·Windows 종료 시 세션 폴더 전체 삭제. 강제 종료 등으로 남은 세션은 다음 실행 때 자동 정리(다른 창에서 실행 중인 세션은 제외). 남는 것은 월 사용량(`usage.json`, 토큰 수만)과 허브 공개 데이터 캐시뿐입니다. '폴더에서 찾기'로 제자리에서 읽은 원본 CSV는 지우지 않으며 퇴실 화면에 그 폴더를 안내합니다.
- 혼디 서버는 이 PC의 혼디 화면에서 온 요청만 받습니다(다른 웹사이트의 위조 요청·DNS 재바인딩 차단).

## 7. 오류·제약사항

| 상황 | 동작 |
|---|---|
| 인터넷 끊김·OpenAI 장애·월 한도 초과 | 자동으로 질문 카드 모드. 분석·반출 점검·보고서는 정상 |
| AI가 잘못된 계획(없는 컬럼 등) | 검증에서 걸러 1회 재시도, 그래도 틀리면 가장 가까운 질문 카드로 대체하고 알림 |
| 아주 큰 파일(월 수십만 행 × 12개월) | DuckDB 메모리 처리. 32GB PC에서 수백만 행 문제없음. 업로드 1회 300MB 제한 |
| 센터가 컬럼 구성을 바꿈 | 명세서를 새로 받아 `tools/build_catalog.py`로 카탈로그 재생성 |
| 같은 PC를 여러 이용자가 사용 | 이용자마다 실행.bat을 새로 켜고, 끝나면 퇴실 버튼 |
| 반출 신호등 | 예상일 뿐이며 최종 판단은 센터 심사 |

## 8. 센터 PC 보안정책: 확장 모듈 허용 등록

센터 PC는 디지털 서명이 없는 파이썬 확장 모듈(.pyd/.dll)의 실행을 막지만, **센터 운영자가 허용 등록하면 사용할 수 있습니다**(대회 게시판 답변 2026-11-15).

| 패키지 | 버전 | 용도 | 확장 모듈 파일 수 |
|---|---|---|---|
| duckdb | 2.0.0 | 분석 엔진(집계) | 1 |
| numpy | 2.5.4 | 그림 계산(matplotlib 의존) | 21 |
| matplotlib | 3.11.2 | 그림 | 8 |
| pillow | 13.0.0 | 그림 저장(PNG) | 8 |
| fonttools | 4.68.0 | 글꼴 처리(matplotlib 의존) | 6 |
| contourpy · kiwisolver | 1.4.0 · 1.5.1 | matplotlib 의존 | 각 1 |
| cycler · packaging · pyparsing · python-dateutil · tzdata | — | matplotlib 의존(순수 파이썬) | 0 |

- 설치.bat이 끝나면 설치 폴더에 **`확장모듈_목록.txt`**가 생깁니다. 여기에 허용 등록할 폴더(`.venv\Lib\site-packages`)와 파일 46개의 전체 경로가 적혀 있습니다.
- 등록이 안 된 상태로 실행하면 설치 점검의 '분석 엔진(duckdb)' 또는 '그림(matplotlib)'이 [문제]로 나오고, 혼디 화면 위쪽에도 안내가 뜹니다.
- 혼디 자체 코드는 순수 파이썬과 HTML·JS이며, 별도 실행 파일(.exe)을 설치하지 않습니다.

## 9. 업데이트·제거

- 업데이트: 새 ZIP을 같은 폴더에 덮어쓰고 설치.bat 다시 실행(config.ini는 유지).
- 제거: 폴더 삭제 + `%LOCALAPPDATA%\Hondi` 삭제.
