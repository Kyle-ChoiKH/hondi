# 데이터 활용 명세

혼디가 쓰는 데이터, 쓰는 방법, 가공·반출 처리를 정리합니다. 근거 문서: 「제주빅데이터센터 데이터명세서(v13)」, 「데이터 반출 기준(2026.09.01 개정)」, 「제주빅데이터센터 이용방법」.

## 1. 원칙

| 원칙 | 구현 |
|---|---|
| 센터 데이터는 센터 PC 안에서만 | 사용자가 센터 조회 화면에서 내려받은 CSV만 입력. 서버는 127.0.0.1 전용 |
| 외부 AI에 센터 값 전송 금지 | 질문 속 값은 〔자리표시자〕로 가림(`app/firewall.py`). 시스템 프롬프트는 공개 명세만 |
| 반출은 가공 결과만 | 원본 행·발췌는 결과물에 포함하지 않음. 10 미만 처리·역산 방지(`app/guard.py`) |
| 출처 표기 | 그림·보고서·신청서마다 "출처: 제주빅데이터센터, 데이터명(기간)" |
| 퇴실 시 삭제 | 세션 폴더 삭제(`app/session.py`) |

### 파일 입력 규칙(게시판·이용방법 근거)
- 조회·다운로드는 1개월 단위 → 여러 파일을 데이터별로 자동 병합. 같은 내용 파일은 해시로 중복 제거. 빠진 달 표시.
- 파일명 `Results_YYYYMMDD_HHMMSS.csv`, UTF-8, 따옴표, 결측 `NA` → 모든 열을 문자로 읽은 뒤 명세의 형식으로 변환.
- 명세에 없는 추가 컬럼은 무시하고 알림.

### 가상 컬럼(혼디가 만드는 묶음, 범주처리용)
| 가상 컬럼 | 만드는 방법 |
|---|---|
| 분기·연 | 기준년월 → 분기/연 |
| 업종 대분류 | 업종코드 첫 글자 → 소매 / 운송 / 숙박·음식 / 임대 / 여행·행사 / 오락·스포츠 / 개인서비스 / 기타 |
| 연령 구간 | 연령 → 10~30대 / 40~50대 / 60대 이상 / 미상 |
| 이용자 묶음 | 이용자구분 → 내국인·법인(제주도민 포함) / 외국인 |

## 3. 분석 도구(8종, `app/tools.py`)

| 도구 | 계산 | 집계 유형(반출 기준) |
|---|---|---|
| 추이(trend) | 기간별 합계 | 단순집계 |
| 전년 대비(yoy) | 같은 달 1년 전 대비 증감률 | 응용집계 |
| 구성비(share) | 항목별 비중(%) | 응용집계 |
| 순위(rank) | 합계 기준 상위 N과 순위 | 단순집계(순위만 보이면 응용) |
| 비교(compare) | 두 조건의 같은 항목 합계와 차이(%) | 단순+응용 |
| 증감 기여(contribution) | 두 기간 사이 항목별 증감과 기여율 | 응용집계 |
| 지역 현황(profile) | 한 지역의 총액·건수·주요 업종 비중 | 혼합 |
| 기술통계(describe) | 월별 값의 평균·중앙값·최소·최대·표준편차 | 응용집계 |

모든 계산은 DuckDB SQL(값은 바인딩 파라미터, 컬럼은 명세 화이트리스트)로만 수행합니다. AI는 SQL을 쓰지 않고 위 도구를 고르는 계획(JSON)만 만듭니다.

## 4. 반출 기준 적용(`app/guard.py`)

| 반출 기준 | 혼디 점검 | 고치기 |
|---|---|---|
| 단순집계 10 미만 수치 비공개 | 칸마다 바탕 건수와 최종 값 자체를 모두 확인(합계·평균·1인당 값 등 사칙연산 값과 금액 포함, 게시판 답변 2026-11-15) | 범주처리, 비율 변환, 삭제처리 |
| 역산 방지 | 한 열에 가린 칸이 1개뿐이면 합계로 역산 가능 → 한 칸 더 가림(가린 칸 0개 또는 2개 이상) | 삭제처리에 자동 포함 |
| 원본 발췌 금지 | 원본 한 행만 묶인 칸 경고 | 범주처리 |
| 응용집계(비율·순위·증감률) | 수치 포함 반출 가능(반출 기준). 다만 분모가 10 미만이면 그 칸도 가림 | 묶기 |
| 결과물 형태 | 그림(PNG)·보고서(PDF)·신청서 문장만 생성, 원본 CSV 내보내기 기능 없음 | — |

신호등은 예상이며 최종 반출 여부는 센터 심사로 결정됩니다(화면·보고서·신청서에 명시).

### 표기
금액은 원 단위 그대로 표기합니다(억·만 원으로 줄여 '3.2'처럼 쓰면 10 미만으로 오해될 수 있어 센터가 원 단위를 권장, 게시판 답변 2026-11-15).

### 8-1. 사용 AI 모델과 활용 범위

| 구분 | 내용 |
|---|---|
| 서비스 안의 AI | OpenAI `gpt-5-nano`(Chat Completions, reasoning_effort=low, JSON 응답) |
| 서비스 안의 AI 활용 범위 | 말로 물은 질문을 분석 계획(도구·데이터·조건 JSON)으로 바꾸는 일만 합니다. 계산·반출 점검·한 줄 요약·해설·보고서는 AI 없이 PC 안의 코드가 합니다. AI에는 〔자리표시자〕로 가린 질문과 공개 명세만 보냅니다. 집계값 해설(선택, 기본 꺼짐)은 설정에서 켤 때만 반출 충족(초록)·30행 이하 표를 보내며, 센터가 허용하기 전에는 끈 채로 운영합니다. |
| AI가 없을 때 | 키 없음·인터넷 끊김·월 한도 초과 시 질문 카드로 동작(말로 묻기를 뺀 모든 기능 사용 가능) |
| 로컬 모델 | 사용하지 않음 |
| 개발 과정의 AI | 코드·문서 작성에 생성형 AI 개발 도구(Anthropic Claude)를 활용했습니다(대회 규칙상 허용). |
